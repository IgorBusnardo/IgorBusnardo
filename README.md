### Projetos

**[pipeline-precos-medicamentos](https://github.com/IgorBusnardo/pipeline-precos-medicamentos)** —
pipeline sobre as listas de preços da CMED/Anvisa: ingestão das planilhas publicadas, star schema em
DuckDB e 28 testes dbt. O resultado contraria o que o setor assume — o reajuste anual não é um teto
único aplicado por todos: só 26% das apresentações subiram no limite, e genérico reajusta mais que
biológico.

**[forecast-varejo-farmaceutico](https://github.com/IgorBusnardo/forecast-varejo-farmaceutico)** —
previsão de vendas do varejo farmacêutico com a PMC/IBGE: carga incremental da API SIDRA, backtest
com origem deslizante e 16 testes pytest. Um baseline sazonal de duas linhas vence o LightGBM na
previsão de 1 mês; o modelo só compensa em 3.
